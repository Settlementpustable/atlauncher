# ATLauncher

### Minecraft launcher focused on modpacks

ATLauncher is a clean, open-source Minecraft launcher with an extensive library of curated modpacks. Install any modpack in seconds, manage multiple instances, and keep everything updated automatically.

<br>

---

## Features

| | |
|:---|:---|
| **Modpack Library** | Hundreds of curated modpacks from ATLauncher, CurseForge, and Modrinth |
| **Instance Manager** | Run multiple Minecraft versions and modpacks side by side |
| **Auto Updates** | One-click updates for your launcher, modpacks, and mods |
| **Open Source** | Transparent, community-developed, and free to use forever |
